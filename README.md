# SuZhuangShu · 消费纠纷材料整理助手

面向消费纠纷的免费材料整理工具，包含在线静态网站和离线单文件版。当前为通用草稿，尚未按某一商家事件进行法律审核。

## 版本
- **在线网站**：仓库根目录 `index.html`，部署到符合当地要求的静态托管平台即可使用。
- **离线版本**：`offline/维权材料生成器-离线版.html`，下载后在浏览器中打开，不需要安装插件或连接网络。

两个 HTML 文件目前功能相同，分别提供便于部署和便于分发的入口。

## 功能
- 输入当事人、交易、退款信息；自动计算未退款金额
- 生成民事起诉状或事实陈述草稿、证据清单
- 导出 TXT、Word 兼容 DOC、打印存为 PDF
- 浏览器本地处理表单，不向服务器上传数据；当前不含使用量统计

## 注意
- 生成的文书仅供整理事实，不能保证法院立案或适用特定程序。
- 根据纠纷实际情况核实被告、管辖、诉讼请求、证据，以及是否已有刑事侦查或破产程序。
- 正式向公众推广前应进行法律审核、移动设备测试与托管合规检查。
- GitHub 源码可公开阅读，但 GitHub Pages 在中国大陆的可用性不作保证，仓库创建不等于已部署可访问网站。
